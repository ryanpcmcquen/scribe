# Example knowledge base

These files show the markdown format Scribe writes. They are examples only and
are **not** Scribe's live knowledge base. The live knowledge base lives in its
own git repo/workspace (default: `~/notes/scribe`), never in this source repo.

- `knowledge/<YYYY-MM>/<YYYY-MM>-knowledge.md`
- `reminders/<YYYY-MM>/<YYYY-MM>-reminders.md`
